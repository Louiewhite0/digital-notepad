# Digital Notepad

A browser-based text editor with local saving.

## Features

- Automatic saving
- Character count
- TXT file export

## How to Use

Type your notes and download them when needed.

## Technologies

- HTML
- CSS
- JavaScript

## Running Locally

Open `index.html` in a modern web browser.
## Manual Testing Checklist

- [ ] Type text and confirm the save status.
- [ ] Refresh and verify that the note remains stored.
- [ ] Export a TXT file and inspect its contents.
